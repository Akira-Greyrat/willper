# 重启后的一次性验收（约两分钟）

重启前先别点侧栏图标：当前进程里跑的是旧一代模块，点开只会报 `unknown op`。

## 怎么重启

完全退出 DeepSeek Harness（不是关窗口，是退出进程），再打开。插件是 link 到 `D:\Struggle\Workspace\willper\learning-center` 的，重启后加载的就是最新代码。
