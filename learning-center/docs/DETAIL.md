# 学习中心

把一份**问答题库**变成能按知识点一题一题过下去的学习材料。

## 它做什么

- 把 PDF / Markdown / 文本里的问答题导入成结构化题库：题干、参考答案、要点、知识点归属、来源页码。
- 拆一副知识点骨架，让题目挂在知识点上；过题时按骨架走。
- 题干里的术语点一下就有释义（释义在导入时生成，点击不花时间、不调模型）。
- **没解析干净的题不会混进练习**：缺答案、被截断、重复、答案对不上、跑出范围的，全部进「待核对」并写明原因，等你接受、手改或驳回。

## 数据在哪

全部在**发起学习的那个会话的工作目录**下的 `learning/` 里，都是人能读、能 diff 的文本文件：

```
learning/
  meta.json        目标、知识点树、阶段计划、设置
  questions.jsonl  题库，一行一题
  terms.json       术语表
  attempts.jsonl   作答记录
  progress.json    已读、收藏、薄弱计数
  inbox/           AI 写好的草稿，等你入库
  materials/       原始材料 + 抽取出的纯文本
  reports/         体检报告
```

可以备份、可以搬走、可以进 git。

## 哪些事会请 AI 做

拆知识点、评估题库、判分、回答追问——这些都发生在你当前这个会话里，你能看到全过程和记录。学习中心自己不会在后台调模型。

## 已知限制

- 题目配图只记「原文第 N 页」，不抽取图片；点开会在右侧文档页看原文。
- 第一版只做「导入 → 过题 → 待核对」这条闭环；抽查判分、错题本、体检报告在后续版本。
- 一个工作目录对应一个学习目标；要学第二门，换个目录。
